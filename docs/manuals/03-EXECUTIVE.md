# The Executive's manual

*Last checked against the running system on 2026-10-01.*

The Executive role is deliberately narrow and was built in three steps, each
after the owner said what it should and should not reach. This is where it
stands.

---

## ⚠️ Read this first: you will see no leads today

Measured on 2026-10-01, signing in as Saad Mustafa:

- `/leads` **opens** — the Campaign & Lead Desk appears
- It shows **zero leads**
- There is **no Growth section in the sidebar**

That is not a fault in the desk. The CRM is still restricted to a named list of
people (`crm_preview_members`), and the Executive is not on it. Until the owner
adds you, the lead screens will be empty whichever way you reach them.

**Everything else below works today.** The lead desk is the one part waiting on
that decision.

---

## What you can do

### Run the work

You can create and assign tasks, and keep full control of them afterwards —
content, dates, status, approvals. You may assign to anyone you outrank.

**Work → Tasks** is yours. So is **Workload**, which shows what each person is
carrying before you give them more.

This was widened on purpose. The role began read-only; the owner reversed that
on 2026-09-26: *"he can assign a task to a team member … he can view tasks and
everything like that."*

### See the business

| | |
|---|---|
| **Dashboard** | the control room |
| **Reports** | the team's output |
| **Performance** | per person |
| **Projects** | every project |
| **Attendance** | who came in, when |
| **Trend & Engagement Studio** | what is being published |

### The lead desk, once you are on the preview list

When the owner adds you, you will see what a sales manager sees — every lead on
the department's projects, the sharing-out control, and both report screens.
[`02-SALES-MANAGER.md`](02-SALES-MANAGER.md) describes all of it.

---

## What you cannot do

| | |
|---|---|
| Open the **Vault** | closed to the Executive on purpose (migration 259) |
| Create another Executive | only an Admin |
| Change system settings or security | only an Admin |
| Add somebody to the CRM preview | only an Admin |

## Not built yet

The same gaps everybody has: no lead merging, no tags, no branch or territory,
and Google Ads and TikTok are listed as *coming soon* rather than connected.

## Try this in ten minutes

1. **Dashboard** — does it load with real figures?
2. **Tasks** — create one and assign it to a team member. Can you then change its
   date and status?
3. **Workload** — does it show each person's load?
4. **Vault** — you should be refused. That is correct.
5. **Growth → Campaign & Lead Desk** — if it is missing from the sidebar, or
   opens empty, that is the preview list, not a bug. Ask the owner to add you and
   try again.

Report anything else, with the step number.
