# Decision Log (ADRs)

One file per **locked** decision. Once a decision lands here, it's settled — we don't relitigate it without a new ADR that supersedes it.

## Naming
```
ADR-001-choose-postgres.md
ADR-002-team-lead-role.md
```

## Template

```markdown
# ADR-NNN — <Short title>

**Date:** YYYY-MM-DD
**Status:** Accepted | Superseded by ADR-NNN | Rejected
**Decided by:** <who>
**Relates to:** Q-0NN, doc NN

## Context
What situation forced a decision.

## Options considered
| Option | Pros | Cons |
|---|---|---|

## Decision
What we chose.

## Why
The reasoning, honestly stated — including what we're giving up.

## Consequences
What this makes easier. What it makes harder. What we'd have to undo if we change our minds.
```
